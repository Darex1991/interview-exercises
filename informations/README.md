# Informacje – System Design, Mikroserwisy, Frontend & AI

Zbiór notatek przygotowanych pod rozmowy rekrutacyjne / powtórkę wiedzy na temat projektowania systemów rozproszonych i architektury mikroserwisowej.

- [system-design.md](./system-design.md) – podstawy system design: skalowanie, load balancing, cache, bazy danych, CAP theorem, kolejki, rate limiting, podejście do rozwiązywania zadań na rozmowie.
- [microservices.md](./microservices.md) – mikroserwisy: różnice vs monolit, komunikacja między serwisami, wzorce (API Gateway, Saga, Circuit Breaker, Database per Service), obserwowalność, wyzwania.
- [nextjs-architecture.md](./nextjs-architecture.md) – poprawna architektura aplikacji w Next.js (App Router): Server vs Client Components, struktura katalogów, warstwy cache, Server Actions, strategie renderowania, middleware, częste błędy.
- [frontend-interview-questions.md](./frontend-interview-questions.md) – pytania i odpowiedzi na rozmowę frontendową: JS/CSS/React, DSA, machine coding, behawioralne, HLD, LLD, data pipelines, skalowalność, REST API.
- [what-to-remember.md](./what-to-remember.md) – przebieg typowego procesu rekrutacyjnego frontend (test automatyczny + rozmowa techniczna) i jak się do niego przygotować.
- [ai-coding-tools.md](./ai-coding-tools.md) – narzędzia AI do kodowania (Claude Code, Cursor, Copilot): słowniczek (LLM, token, context window, agent, tool call, MCP), typy narzędzi, pliki reguł (CLAUDE.md, .cursor/rules), po co są skille/subagenty/hooki, dobre praktyki pracy z agentem i pytania rekrutacyjne.
